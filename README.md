## 📌 About This Repository

This repository represents a **structured, project-based approach to mastering Python** — starting from core fundamentals and progressing toward applied development.

It includes:

- Core Python fundamentals  
- Object-Oriented Programming (OOP)  
- File handling & system interaction  
- Practical console-based applications  
- Introductory GUI development using PyQt5  
 
Every concept is implemented and reinforced through hands-on exercises and structured mini-projects.
